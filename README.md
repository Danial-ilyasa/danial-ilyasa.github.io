# Portofolio Danial Ilyasa

Website portofolio personal yang dibuat untuk menampilkan profil, pengalaman, keterampilan, proyek, dan informasi kontak dari Danial Ilyasa.

## Deskripsi

Project ini merupakan landing page personal yang dirancang dengan tampilan modern, responsif, dan minimalis. Website ini berfungsi sebagai media online untuk memperkenalkan diri sebagai mahasiswa informatika dan pengembang yang tertarik pada teknologi web, pemecahan masalah, serta pengembangan solusi digital.

Website ini menampilkan beberapa section utama, antara lain:

- Hero section dengan intro diri dan tombol navigasi
- About section untuk memperkenalkan latar belakang dan fokus bidang
- Skill section yang menampilkan teknologi yang dikuasai
- Project section untuk menampilkan karya dan proyek terbaru
- Contact section untuk memudahkan pengguna menghubungi melalui email atau media sosial

## Teknologi yang Digunakan

- React
- Vite
- Tailwind CSS
- React Feather Icons
- CSS custom untuk styling tambahan

## Fitur Utama

- Desain yang modern dan profesional
- Responsif untuk desktop dan mobile
- Animasi sederhana untuk pengalaman pengguna yang lebih baik
- Navigasi antar section yang smooth
- Tombol yang mengarahkan ke GitHub, LinkedIn, Instagram, dan email

## Repository

Website ini dapat digunakan sebagai template portofolio pribadi atau dikembangkan lebih lanjut sesuai kebutuhan.
